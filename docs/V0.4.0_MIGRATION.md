# Migration Guide: v0.3.0 → v0.4.0

## Overview

v0.4.0 is a backwards-compatible release that adds new evidence taxonomy, synthetic
validation corpus, optional PyOD baselines, regime/anomaly/regression separation layer,
conformal calibration design documentation, and new documentation files.

All changes are **additive only** — no existing CLI commands, output schemas, or APIs
are modified in breaking ways.

## New Python API

### EvidenceRecord

```python
from anomaly_lab.evidence import EvidenceRecord, EvidenceClass, classify_detection_evidence

result = rz_fit(df, ["latency"])
evidence = classify_detection_evidence(result)
print(evidence.evidence_class)  # e.g. "POINT_ANOMALY"
print(evidence.confidence)  # 0.0–0.95
print(evidence.interpretation)  # human-readable string
print(evidence.to_dict())  # serialisable dict
```

### classify_observation

```python
from anomaly_lab.classify import classify_observation, RegimeAnalysisResult

# With detection results only
evidence = classify_observation(detection_results=[result], comparison_result=None, regime_result=None)

# With regime analysis
regime = RegimeAnalysisResult(regime_detected=True, regime_count=2, ...)
evidence = classify_observation(detection_results=None, comparison_result=None, regime_result=regime)
```

## New CLI Detectors (requires `pip install 'anomaly-lab[pyod]'`)

| Detector | Description |
|----------|-------------|
| `ecod` | ECOD (Empirical CDF-based Outlier Detection) |
| `lof` | Local Outlier Factor (k-NN) |
| `knn` | Median k-NN distance |

Usage:
```bash
anomaly-lab analyze data.csv --detector ecod --features latency
anomaly-lab analyze data.csv --detector lof --features x,y
anomaly-lab analyze data.csv --detector knn --features x,y
```

If pyod is not installed, these emit a clear error message pointing to the install command.

## Upgrading from v0.3.0

### For Users

1. **No action required** — existing commands work unchanged.
2. **Optional**: install `pip install 'anomaly-lab[pyod]'` to access ECOD, LOF, KNN detectors.
3. **Optional**: use `classify_observation()` to get structured evidence labels.

### For Developers

1. All new files are additive — no existing code needs modification.
2. Run `ruff check src/anomaly_lab/evidence.py src/anomaly_lab/classify.py` to verify.
3. Run `pytest tests/test_synthetic_corpus.py -v` to verify the synthetic corpus.

### For Integrators

1. The EvidenceRecord JSON output can be appended to existing DetectionResult output.
2. The new `evidence_class` field is a string enum matching `EvidenceClass` values.
3. Confidence values are always in [0.0, 0.95] — never 1.0.

No existing APIs are deprecated in v0.4.0. This release is purely additive.
